4. **DW-04 (High — Future Timestamp `u64::MAX` Underflow Bypass)**: Fixed in [`src/egress_ips.rs`](file:///Users/jean-baptiste/AI-TrustChain/src/egress_ips.rs) via `is_past_skew_or_forged_future`.
5. **DW-05 (High — Nudged Timestamp `PduAltered` Correlation)**: Fixed in [`src/egress_ips.rs`](file:///Users/jean-baptiste/AI-TrustChain/src/egress_ips.rs) via two-tier exact + skew-bounded slot correlation.
6. **DW-06 (High — Ingress Ring-Buffer Eviction Desync)**: Fixed in [`src/ingress_ips.rs`](file:///Users/jean-baptiste/AI-TrustChain/src/ingress_ips.rs) by separating `next_pdu_seq` from `cumulative_pdu_count`.
7. **DW-07 (Medium — Control Frame Replay Rollback)**: Fixed in [`src/egress_ips.rs`](file:///Users/jean-baptiste/AI-TrustChain/src/egress_ips.rs) with `CryptoError::ControlFrameReplay`.
8. **DW-08 (Medium — Storage Partial-Write Offset Rollback)**: Fixed in [`src/storage.rs`](file:///Users/jean-baptiste/AI-TrustChain/src/storage.rs) by truncating and seeking back to `active_file_len` if `write_all` or `sync_data` fails.

## 2. Second-Pass Audit Additions
- **Cross-Session Sequence Rollback Guard**: Hardened [`EgressIps::receive_control_frame`](file:///Users/jean-baptiste/AI-TrustChain/src/egress_ips.rs#L177-L197) so an attacker cannot replay a mid-stream frame from an older `boot_session_id` to roll back `expected_frame_seq`.
- **Ethernet L2 Trailer Padding Strip in PCAP Parser**: Hardened [`parse_ethernet_ipv4_frame`](file:///Users/jean-baptiste/AI-TrustChain/src/pcap_verifier.rs#L287-L361) to slice the IPv4 packet strictly by the IPv4 `Total Length` header field so 64-byte minimum Ethernet padding bytes are never mistaken for transport payload bytes.
