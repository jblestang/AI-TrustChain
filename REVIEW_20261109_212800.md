## 1. Systems / Filesystem Durability & Power-Failure Safety Review

| ID | Severity | Finding | Status / Resolution |
| :--- | :--- | :--- | :--- |
| **SYS-01** | High | A sudden power outage during `append_frame` can leave a partially written header, truncated payload, or un-flushed OS page-cache buffer at the end of the active `.tclog` segment. | **Verified**: Every record in [`RotatingControlStore`](file:///Users/jean-baptiste/AI-TrustChain/src/storage.rs#L75-L86) is framed with `u32` big-endian length + 64-bit `BLAKE3(len_be \|\| payload)` checksum and committed via `File::sync_data()` (`fsync`). | **SYS-02** | Medium | Creating a new segment file or unlinking an expired segment during rotation requires syncing the parent directory entry on POSIX filesystems so directory metadata survives power loss. | **Verified**: `sync_directory` invokes `sync_all()` on the directory descriptor whenever segments are created or rotated. |
| **SYS-03** | Medium | Unbounded disk usage if the system runs unattended for months. | **Verified**: [`StorageConfig`](file:///Users/jean-baptiste/AI-TrustChain/src/storage.rs#L43-L50) enforces both `max_segment_bytes` and `max_segments`, deleting the oldest `segment_<seq>.tclog` files in FIFO order. |
