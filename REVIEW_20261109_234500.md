## 1. Security & Cryptographic Review of the Decoupled Storage VM

| ID | Severity | Finding | Status / Resolution |
| :--- | :--- | :--- | :--- |
| **VM-01** | High | **Least-Privilege Key Separation**: If the Storage VM held `TrustChainKeys` (`pdu_mac` and `control_aead`), a compromise of the Storage VM would allow an attacker to decrypt `ControlPayload` metadata or forge control frames and PDU MACs. Conversely, if the Storage VM held *no* key, an attacker on the network could flood the Storage VM with garbage frames and rotate legitimate segments off the disk. | **Resolved**: Derived a third domain-separated subkey (`storage_verify`) exported as [`StorageVerificationKey`](file:///Users/jean-baptiste/AI-TrustChain/src/crypto.rs#L74-L78) (`ZeroizeOnDrop`). [`EncryptedControlFrame`](file:///Users/jean-baptiste/AI-TrustChain/src/model.rs#L179-L191) carries a 128-bit outer `storage_auth_tag`. [`StorageVmNode::receive_and_persist_frame`](file:///Users/jean-baptiste/AI-TrustChain/src/storage.rs#L539-L575) verifies `storage_auth_tag` and enforces anti-replay monotonicity before touching the disk, while keeping `ControlPayload` encrypted and opaque to the Storage VM. |
| **VM-02** | Medium | **Stateless / Diskless Ingress IPS VM**: The Ingress IPS VM observing the trust flow must not depend on local disk I/O or share a filesystem with `RotatingControlStore`. | **Resolved**: Removed all disk/`RotatingControlStore` couplings from [`IngressIps`](file:///Users/jean-baptiste/AI-TrustChain/src/ingress_ips.rs). `IngressIps` now operates purely in memory and emits `EncryptedControlFrame` packets over the network to `EgressIps` and `StorageVmNode`. |
| **VM-03** | Medium | **Multi-Session Frame Ordering on Storage VM**: When the stateless Ingress IPS VM reboots after a power cycle, it generates a fresh `boot_session_id` and starts at `frame_seq = 0`. Sorting live frames on the Storage VM solely by `frame_seq` could reorder frames across boot sessions or deduplicate two distinct sessions' `frame_seq = 0`. | **Resolved**: [`RotatingControlStore::read_all_frames_live`](file:///Users/jean-baptiste/AI-TrustChain/src/storage.rs#L220-L248) preserves chronological segment order across boot sessions and deduplicates by `(sender_id, boot_session_id, frame_seq)`. |
